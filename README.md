# Dota 2 комментатор для Discord

Бот раз в `INTERVAL_MIN` минут проверяет последние матчи игроков через [OpenDota API](https://docs.opendota.com/).
Когда находит новый матч, просит модель из OpenRouter разобрать игру с приколами и пишет разбор в канал Discord.
В разборе есть ход игры, переломные моменты с минутами, оценка каждого игрока, прожарка худшего и MVP.

Если реплей ещё не разобран OpenDota, бот сам заказывает разбор и ждёт до 4 минут.
Только в разобранном реплее есть график золота, драки, Рошаны, снесённые здания, тайминги предметов и чат.
Если разбор не успел, бот комментирует по итоговой статистике.

- Если в одном матче несколько отслеживаемых игроков, бот пишет **один** комментарий на всех.
- При первом запуске бот только запоминает последний матч каждого игрока, чтобы не писать про старые игры.
- Уже прокомментированные матчи хранятся в `data/state.json`, поэтому после перезапуска дублей не будет.
- Если модель упала, бот пробует следующую из `OPENROUTER_MODELS`. Если не ответила ни одна, матч повторяется на следующей проверке (максимум 3 попытки).

## Запуск

```bash
npm install
cp .env.example .env   # заполнить
npm start
```

## Шутки по расписанию

Раз в `JOKE_INTERVAL_HOURS` часов (по умолчанию 3) бот пишет в канал шутку про случайного игрока из `PLAYERS` (два раза подряд про одного и того же не шутит), каждый раз в случайном стиле.
Самая первая шутка выходит сразу после первого запуска. Дальше бот помнит время последней шутки, поэтому перезапуск не сбивает расписание.
Последние 10 шуток передаются модели, чтобы она не повторялась. Промпт лежит в `joke-prompt.txt`, проверить его можно командой `npm run test-joke`.

## Команда /match

В Discord напишите `/match id:9066099884`. Вместо id можно вставить ссылку на матч в Dotabuff или OpenDota.
Необязательный параметр `style` задаёт стиль только для этого ответа.

Если в матче есть кто-то из `PLAYERS`, бот комментирует их. Если нет, он комментирует самого богатого игрока матча и того, кто умер больше всех.
Команда появляется на сервере сразу после запуска бота. Если её нет в списке, пригласите бота заново со scope `bot` + `applications.commands`.

Чтобы проверить стиль и промпт без Discord, запустите комментарий к любому матчу прямо в консоли:

```bash
npm run test-match -- 9066099884
```

## Настройка Discord

1. https://discord.com/developers/applications → New Application → Bot → **Reset Token**. Полученный токен запишите в `DISCORD_TOKEN`.
2. OAuth2 → URL Generator: scope `bot`, права `Send Messages`, `Embed Links`. По ссылке пригласите бота на сервер.
3. В Discord включите режим разработчика, нажмите ПКМ по каналу → «Копировать ID» и запишите результат в `DISCORD_CHANNEL_ID`.

## Переменные

| Переменная | Описание |
|---|---|
| `DISCORD_TOKEN` | токен бота |
| `DISCORD_CHANNEL_ID` | канал для комментариев |
| `OPENROUTER_API_KEY` | ключ OpenRouter |
| `OPENROUTER_MODELS` | модели через запятую, в порядке приоритета (fallback) |
| `STYLE` | `random`, один из готовых стилей, несколько через запятую или свой текст (см. ниже) |
| `MAX_CHARS` | максимальная длина разбора, по умолчанию 5000; ответ длиннее 2000 символов разбивается на несколько сообщений |
| `TEMPERATURE` | креативность модели |
| `PLAYERS` | `ник:имя:id,ник2:имя2:id2`, где id — число из `dotabuff.com/players/<id>` (Steam64 тоже подойдёт) |
| `ROAST_TARGET` | имена через запятую, над кем бот шутит в каждом разборе, даже если человек не играл |
| `JOKE_INTERVAL_HOURS` | раз в сколько часов бот шутит про случайного игрока из `PLAYERS` (0 — не шутить), промпт в `joke-prompt.txt` |
| `INTERVAL_MIN` | период проверки в минутах |
| `OPENDOTA_API_KEY` | необязательно |
| `PROMPT_FILE` | файл промпта: `./prompt.txt` (разбор с упором на шутки, по умолчанию) или `./prompt-short.txt` (одно сообщение, ставьте вместе с `MAX_CHARS=1800`) |
| `STATE_FILE` | необязательно, по умолчанию `./data/state.json` |

### Стили

`caster` — комментатор TI, `gopnik` — пацан с района, `shakespeare`, `pirate`, `noir` — нуарный детектив,
`grandma` — бабушка, `toxic` — токсичный тиммейт, `philosopher`, `rap` — рэп-баттл, `news` — вечерние новости,
`nature` — передача о дикой природе, `medieval` — древнерусский летописец, `corporate` — менеджер на ретро.

Стили задаются в `src/styles.js`, туда же можно добавить свои.

## Важно

У игроков в настройках Dota 2 должна быть включена опция **«Открыть доступ к данным матчей» (Expose Public Match Data)**.
Без неё OpenDota не увидит их матчи.
